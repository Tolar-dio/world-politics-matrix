# World Politics Matrix

A clickable 3D globe of where every country stands in 2026. Click a country (or search for it) to get:

- **The 2026 write-up** from the *World in 2026* country summaries series, with every source linked
- **How power works** and **who holds power**
- **Culture** and **Society** portraits, plus a few descriptors
- A fact sheet: capital, population, area, languages, religion, currency, system of government

The globe can be coloured three ways: by **system of government**, by **what defined 2026** for that country, or by **which Part of the series** covers it.

Countries without a 2026 write-up yet still get a profile, clearly marked as not yet verified for this year.

## Viewing the site

The site is plain HTML, CSS and JavaScript, so GitHub Pages can host it for free.

**Turning on GitHub Pages (one time):**

1. Open the repo on GitHub: `github.com/Tolar-dio/world-politics-matrix`
2. Click **Settings** (the gear tab along the top of the repo).
3. In the left sidebar, click **Pages**.
4. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
5. Set **Branch** to `main` and the folder to `/ (root)`, then click **Save**.
6. Wait a minute or two, then refresh the page. A link appears at the top: `https://tolar-dio.github.io/world-politics-matrix/`

Every time new commits land on `main`, the site updates itself within a couple of minutes.

**Opening it on your own computer:** the page loads its data with `fetch`, so double-clicking `index.html` won't work. From the repo folder, run `python3 -m http.server` and open `http://localhost:8000`.

## How the content is organised

```
content/
  2026/part-1.md … part-5.md   The country write-ups, one file per Part of the series
  profiles/*.yaml              Culture, society, descriptors and facts for every country, by region
scripts/
  build.py                     Turns content/ into the JSON the site reads
  docxml2md.py                 Converts a Claude Docs export of a Part into a part-N.md file
  source/                      Base country facts and map shapes (don't edit by hand)
data/                          Generated by build.py. Don't edit by hand.
assets/                        The site itself: app.js, style.css, vendored globe libraries
```

### Adding a new Part of the series

1. Create `content/2026/part-6.md` (and so on). It starts with a small header, then regions and countries:

   ```markdown
   ---
   part: 6
   title: "The World in 2026: Country Summaries, Part 6"
   as_of: 2026-11-01
   ---

   ## Africa

   ### Angola

   First paragraph of the story, with sources as links like ([Reuters](https://...)).

   Second paragraph.

   **How power works:** One paragraph.

   **Who holds power:** One line.
   ```

   `##` is a region, `###` is a country. Paragraphs are separated by a blank line. A country that appears in more than one Part shows the most recent write-up.

2. In `content/profiles/<region>.yaml`, give the country a `story:` key so it shows up on the "What defined 2026" map: one of `war`, `election`, `unrest`, `shock` or `steady`. You can also remove its `baseline:` and `leaders:` lines, since the write-up replaces them.

3. Rebuild the data and commit:

   ```bash
   pip install pyyaml        # first time only
   python3 scripts/build.py
   git add -A && git commit -m "Add Part 6" && git push
   ```

   The build stops with a clear message if a country heading doesn't match a known country name.

### Profile fields

Each entry in `content/profiles/*.yaml` is keyed by the country's three-letter code:

| Field | What it is |
|---|---|
| `pop` | Population in millions (roughly mid-2025 estimates) |
| `religion` | Main religions, in a few words |
| `system` | One of `presidential`, `semi-presidential`, `parliamentary`, `const-monarchy`, `exec-monarchy`, `one-party`, `military`, `religious`, `contested` |
| `system_note` | Optional one-line qualifier |
| `story` | 2026 storyline key (only for countries with a write-up) |
| `snapshot` | One or two sentences shown on hover and at the top of the profile |
| `tags` | Four to six short descriptors |
| `culture`, `society` | Paragraphs; a blank line starts a new paragraph |
| `baseline`, `leaders` | Only for countries still waiting for a write-up |
